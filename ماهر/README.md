# ⚡ نظام إدارة ديون ومشتركي المولدة - لوحة تحكم ماهر

نظام متكامل واحترافي يعمل بالكامل باللغة العربية ومصمم خصيصاً لأصحاب المولدات الكهربائية لإدارة المشتركين، تسجيل الأمبيرات، حساب الديون، تسجيل الدفعات النقدية، وإصدار الوصولات والتقارير.

---

## 🚀 طريقة التشغيل السريعة

1. **الطريقة الأسهل:**
   - اضغط مرتين (Double Click) على ملف:
     `تشغيل_الموقع.bat`
   - سيتم تشغيل السيرفر المحلي تلقائياً وفتح الموقع في متصفحك.
   - ستظهر لك أيضاً نافذة تعرض لك رابطاً لفتح الموقع من هاتفك المحمول عبر شبكة الواي فاي المحلية.

2. **الفتح المباشر بدون سيرفر (Offline):**
   - اضغط مرتين مباشرة على ملف `index.html` وسيفتح فوراً في المتصفح بكل وظائفه.

---

## 🌟 أبرز مميزات النظام

- **📊 لوحة إحصائيات سريعة (KPIs):**
  - إجمالي مبالغ الديون المطلوبة حالياً من المشتركين.
  - إجمالي المبالغ المحصلة والمسددة.
  - إجمالي عدد المشتركين والنشطين منهم.
  - مجموع الأمبيرات المسحوبة على المولدة.
  - سعر الأمبير الافتراضي.

- **👥 إدارة المشتركين والديون:**
  - إضافة وتعديل المشتركين (الاسم، الهاتف، المنطقة أو رقم العمود، عدد الأمبيرات، وسعر الأمبير الخاص، والرصيد الافتتاحي).
  - تحديد حالة المشترك (نشط / متوقف مؤقتاً).
  - حذف أو أرشفة المشتركين.

- **💵 تسجيل الدفعات والوصولات:**
  - تسجيل دفعات كاملة أو جزئية بنقرة زر.
  - طباعة وصل استلام حراري فوري (80mm) أو A4 يحتوي على تفاصيل الدفعة والدين المتبقي واسم المشترك.
  - كشف حساب كامل لكل مشترك يوضح تاريخ كل اشتراك أو دفعة سابقة.

- **📅 ترحيل وتوليد اشتراك الشهر الجديد:**
  - إضافة استحقاق الاشتراك الشهري لكل المشتركين النشطين بنقرة واحدة بحسب سعر الأمبير للشهر المحدد.

- **💬 تواصل مباشر عبر واتساب:**
  - زر لمراسلة المشترك تلقائياً عبر واتساب برسالة جاهزة ومهذبة تطالبه بالرصيد المتبقي بذمته.

- **📑 طباعة كشف الديون الميداني (PDF / Print):**
  - طباعة جدول أنيق ومرتب بأسماء المشتركين المدينين وأرقام هواتفهم وعناوينهم وأمبيراتهم لحملها أثناء الجولة الميدانية لجمع المستحقات.

- **📥 تصدير واستيراد Excel:**
  - إمكانية تصدير كامل البيانات إلى ملف Excel بضغطة زر.
  - استيراد المشتركين والديون من ملف Excel بسهولة.

- **🛡️ أمان وحفظ البيانات (النسخ الاحتياطي):**
  - البيانات تُحفظ تلقائياً في المتصفح دون الحاجة لاتصال بالإنترنت.
  - إمكانية تحميل نسخة احتياطية كاملة (ملف JSON) واسترجاعها في أي وقت بنقرة واحدة.
