# ⚡ نظام إدارة ديون ومشتركي المولدة - السيد ماهر

تم فصل النظام إلى **واجهتين مستقلتين تماماً** لضمان الخصوصية وسهولة الاستخدام:

---

## 1️⃣ واجهة الزبون / بوابة المشتركين (`index.html` أو `customer.html`)
هذه هي الصفحة العامة التي يراها أي شخص أو مشترك عند فتح الرابط:
* **خصوصية تامة:** المشترك **لا يستطيع** رؤية أسماء المشتركين الآخرين أو ديونهم أو أرقامهم.
* **البحث والاستعلام:** يكتب الزبون رقم هاتفه أو اسمه المسجل في خانة البحث فتظهر له بطاقة حسابه الشخصية فقط.
* **بيانات الفاتورة:**
  - عدد الأمبيرات المشترك بها.
  - قيمة الاشتراك الشهري.
  - إجمالي الدين المطلوب المتبقي في الذمة.
  - سجل بآخر الحركات والدفعات التي سددها مع تواريخها.
  - زر لمراسلة مسؤول المولدة مباشرة عبر واتساب لتأكيد الدفع أو الاستفسار.

---

## 2️⃣ واجهة الإدارة المحمية (`admin.html`)
لوحة التحكم الكاملة والخاصة بمسؤول المولدة (السيد ماهر):
* **حماية برمز أمان (PIN):** لا يمكن لأي زبون الدخول إليها إلا بكتابة الرمز السري:
  - 🔑 **الرمز الافتراضي:** `1234`
  - (يمكنك تغييره في أي وقت من زر الإعدادات ⚙️).
* **إدارة كاملة:**
  - إضافة وتعديل وحذف المشتركين.
  - تسجيل دفعات نقدية وإصدار وصولات استلام (حرارية 80mm أو A4).
  - ترحيل اشتراك الشهر الجديد بنقرة زر لجميع المشتركين.
  - تصدير واستيراد ملفات Excel.
  - أخذ نسخة احتياطية (JSON).
  - إرسال رابط الفاتورة المباشر لكل مشترك بنقرة زر عبر الواتساب.

---

## 🚀 طريقة التشغيل والرفع على النت

1. **للتشغيل على جهاز الكمبيوتر:**
   - اضغط مرتين على `تشغيل_الموقع.bat` وسيعمل مباشرة.

2. **للرفع المجاني على الإنترنت:**
   - ادخل على الرابط المجاني: [app.netlify.com/drop](https://app.netlify.com/drop)
   - اسحب مجلد `ماهر` وأفلته في الصفحة، وسيعطيك رابطاً مجانياً ومباشراً ترسله للمشتركين!
